This is the repository for TWINFER - a framework for gene regulatory network inference using single-cell transcriptomic data and twin cells. 

TwINFER_simulation_and_analysis.ipynb is the notebook to create simulations with any gene regulatory network and gene parameters and then use TwINFER framework to infer the network from the simulation output.

The folder data/parameters_from_literature has all the source files from original literature used to estimate biologically realistic parameter ranges. The /analysis_code/parameter_estimation_from_literature.ipynb has the code used for parameter estimation.

The folder data/simulation_input has a few example interaction matrices and median parameters as an example.
